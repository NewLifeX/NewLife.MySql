# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 11 种语言｜英文为源文与兜底

## 1. 语言分层

本库按 NuGet 下载量分层维护运行时词表：下载量较高的核心组件对齐 NewLife.Core 的 31 种语言，其余组件维护 11 种语言（与 README 读者一致）。缺失译文在运行时自动回退英文，新增语言不需要改代码。

词表文件（10 个，另有英文源文兜底）：

- zh-Hans
- zh-Hant
- es
- de
- ja
- fr
- pt
- ru
- ko
- ar

当前覆盖：主库 49 键、EF6 6 键、EF Core 4 键；10 个语言文件均为真实译文，`report-locales.ps1 -RequireTranslated` 为零缺失、零未翻译。

## 2. 词表文件

- `NewLife.MySql/Locales`
- `NewLife.MySql.EntityFramework/Locales`
- `NewLife.MySql.EntityFrameworkCore/Locales`

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。
- 主驱动通过 `PackageReference` 直接引用 Core，自动导入 `Locales/*.yml`；两个 EF 提供程序只通过 `ProjectReference` 传递引用 Core，`NewLife.Core.props` 不会传递导入，需在 csproj 显式声明 `<AdditionalFiles Include="Locales\*.yml" />`。EF6 的 net45/net461 目标另需内部 `ModuleInitializerAttribute` 兼容垫片，供源生成器注入注册代码。

## 3. 新增一条消息

1. 代码中写英文源文：异常与同步消息用 `L.T`，例如 `throw new InvalidOperationException(L.T("Session {0} is closed.", sessionId));`；日志直接写英文模板（`Logger.Format` 自动翻译）。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

### 3.1 带前缀写日志

动态前缀（实例名、会话编号等）不要拼进格式化字符串，否则整串无法命中词表。先翻译消息再拼接前缀：

```csharp
Log?.InfoPrefixed("[Session] ", "Received {0} bytes", count);
Log?.ErrorPrefixed("[Session] ", "Read error: {0}", ex.Message);
Log?.WritePrefixed(LogLevel.Warn, "[Session] ", "Queue is full: {0}", length);
```

`BinlogClient` 与 `MySqlBulkCopy` 均已提供 `LogPrefix` 属性，默认分别为 `[Binlog] ` 与 `[BulkCopy] `，`WriteLog` 内部走 `InfoPrefixed`。静态前缀可以直接写进源文并作为键的一部分。

### 3.2 覆盖范围

- 驱动自身产生的异常消息与面向用户的日志必须进入词表，服务器返回的错误原文保持原样；`zh-CN`、`zh-TW`、`ja-JP` 等区域文化会自动回退到 `zh-Hans`、`zh-Hant`、`ja` 词表。
- `[MySqlPacket]` 包级调试日志是结构化诊断数据，字段名保持英文以便检索和工具解析，不进入词表。
- 内置日志器在写出时自动翻译；自定义 `ILog` 实现若需翻译，应调用 `Logger.FormatMessage`（或使用 `InfoPrefixed`/`ErrorPrefixed` 扩展）。`BinlogClient` 与 `MySqlBulkCopy` 的 `WriteLog` 已走 `InfoPrefixed`，其消息不依赖日志器实现。

## 4. 校验

```powershell
pwsh -File tools/check-locales.ps1
pwsh -File tools/check-locales.ps1 -LocaleDir NewLife.MySql/Locales -Baseline zh-Hans.yml -SourceDir NewLife.MySql
pwsh -File tools/report-locales.ps1 -RequireTranslated
pwsh -File tools/check-english-exceptions.ps1
```

脚本统一放在 `tools/`，不再放根目录。CI 的 localization job 会遍历全部 `Locales` 目录并执行同一脚本。脚本同时做反向校验：源码中的 `L.T`、`Localization.Translate`、带前缀日志与常用日志入口的字符串必须存在于基准表，避免新增消息漏词表；`-RequireTranslated` 会拒绝与英文原文相同的未翻译项（品牌/协议标识走 `tools/locales-identical.allow.json` 白名单）。

配套脚本：`check-english-exceptions.ps1`（运行时消息英文）、`check-assembly-metadata.ps1`（程序集标题/描述）、`check-config-metadata.ps1`（配置类文案）、`check-readme-coverage.ps1`（README 结构/代码块）、`check-package-consumer.ps1`（NuGet 消费端）、`verify-localization.ps1`（一键串联）。

## 5. 程序集标题与描述

- csproj 的 `AssemblyTitle`/`Description` 写**英文源文**，同一个字符串作为 key 写入本工程 `Locales/zh-Hans.yml`；主库、EF6、EF Core 三个工程各自维护。
- 展示层用 `Localization.Translate(AssemblyTitleAttribute.Title)` 取得译文；程序集元数据本身不随语言改变。
- NuGet 画廊只显示单值描述，无法按访问者语言切换；`PackageDescription` 采用中英双语折中，`README.nuget.md` 由英文 README 生成并保留语言切换入口。
- `tools/check-assembly-metadata.ps1` 校验元数据不含中文且已进入基准词表。

## 6. 配置类元数据

- 配置类/配置项的 `DisplayName`、`Description`、`Category` 写英文源文，XML 注释保持中文（开发者语言）。
- 当前仓库没有 `Config<T>` 配置类；`Common/ConnectAttributes.cs` 的 `_client_*` 是协议字段，保持英文，由 `tools/config-metadata.allow.json` 豁免。
- 配置文件注释写盘翻译由 NewLife.Core 的 `ConfigHelper.LocalizeComment` 负责；魔方设置页由 `DataField.Localize` 负责。
- `tools/check-config-metadata.ps1` 扫描中文元数据。

## 7. 测试、日志观测与 AOT

- `UnitTest/LocalizationTests.cs`：覆盖 10 种语言代表消息、日志探针、程序集标题/描述翻译，以及服务器原文与 `[MySqlPacket]` 追踪保持英文的负向断言。
- `UnitTest.EntityFramework/LocalizationTests.cs`、`UnitTest.EntityFrameworkCore/LocalizationTests.cs`：各自消息在 10 种语言下均有译文。
- 日志观测：`dotnet test UnitTest/UnitTest.csproj -c Release --filter "FullyQualifiedName~LocalizationTests" --logger "console;verbosity=detailed"`，`LogProbe_WritesTranslatedSamples` 会逐语言输出日志样例。
- `AotSmoke` 的 `P5 Localization` 场景验证裁剪后 10 语言词表与标题翻译仍可用。
- `tools/check-package-consumer.ps1` 打包后在临时工程引用本地 nupkg，验证消费端 `Localization.Translate` 与程序集标题翻译。

## 8. 校验收口

- 不翻译：BCL 参数异常（`ArgumentNullException`、`ObjectDisposedException` 等框架标准消息）、服务器返回的 `MySqlException` 原文、`[MySqlPacket]` 结构化追踪、ActivitySource 标签、协议字段名与连接属性名。
- 外部消费方通过公共 `WriteLog` 传入的消息：库无法预知全部文案；示例键 `Rows copied: {0}` 已在词表提供，其它消息由消费方自行注册或回退英文。`tools/locales-extra-keys.json` 用于避免此类键被误判为孤儿键。
- 全量门禁：`tools/check-locales.ps1 -RequireTranslated`、`tools/report-locales.ps1 -RequireTranslated`、`tools/check-readme-coverage.ps1 -RequireFull`。
- `ChangeLog.md` 与 `PackageReleaseNotes` 只在正式发版时更新，日常本地化提交不改。
