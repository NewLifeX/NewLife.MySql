NewLife.MySql — драйвер протокола MySQL на чистом C#, совместимый с ADO.NET, Entity Framework Core и XCode: пул, транзакции, подготовленные запросы, async.

## Установка

```bash
dotnet add package NewLife.MySql
```

## Быстрый старт

```csharp
using var conn = new MySqlConnection("Server=127.0.0.1;Database=test;Uid=root;Pwd=***");
conn.Open();
```

## Возможности

- Высокая пропускная способность и низкая задержка, проверено в продакшене
- Полная поддержка пула соединений, транзакций и асинхронных API
- Цели net45–net10.0 для плавного внедрения в унаследованные системы
